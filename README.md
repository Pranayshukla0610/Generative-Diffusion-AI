# Generative-Diffusion-AI
A complete repository dedicated to Diffusion Models and modern generative AI techniques.  

This repository includes:
- Fundamentals of diffusion models
- Forward and reverse diffusion processes
- DDPM and DDIM implementations
- Noise scheduling and denoising
- Latent diffusion concepts
- Image generation pipelines
- Stable Diffusion basics
- Advanced generative AI projects

## Tech Stack
- Python
- PyTorch / TensorFlow
- Hugging Face Diffusers
- NumPy
- Matplotlib

## Applications
- AI image generation
- Image editing and restoration
- Text-to-image synthesis
- Super-resolution
- Creative AI systems

## Goal
To provide beginner-to-advanced implementations of diffusion models for learning, experimentation, and real-world generative AI applications.
